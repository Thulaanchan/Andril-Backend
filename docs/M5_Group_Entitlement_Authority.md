# Canonical M2 subscription entitlement dependency

Group limits read M2's existing `andril_economy.premium_entitlements` relation. The bridge resolves the creator's account from the private profile in the exact module. It observes the committed record under the PostgreSQL table lock used to coordinate with the canonical upsert, including the first insert. This lock also protects verified absence. An active Monthly or Annual record must have a supported finite expiry to qualify as Premium. Expiry and explicit Free or revoked state use the Free limits. Hidden, malformed or unavailable authority is denied.
