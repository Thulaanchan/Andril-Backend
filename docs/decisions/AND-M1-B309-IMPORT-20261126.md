## IMP-01 — Selection, review and mapping

The user explicitly selects source Portfolio projects, reviews their Title and Description,
and confirms before mutation. Append one new unclassified entry per selected project to the
existing destination CV Projects section. Import Title and Description only; exclude media
and external link references. Preserve all existing CV content and the source Portfolio.
Imported text remains withheld by the existing CV preview/PDF privacy projection.

## IMP-02 — Durable duplicate rejection

Reject repeat imports using stable source Portfolio ID, source project ID and destination
CV ID. Enforce the unique tuple durably and concurrently; text equality is not identity.
The same project may be imported into another owned CV. Do not overwrite prior entries.

## Delegated implementation details and limits

Use a durable, private review record and the existing trusted Learning owner transaction
boundary. A server-generated Portfolio content version plus a private content fingerprint
binds confirmation to reviewed source state; actual source changes invalidate the review,
including change-and-revert. Identical explicit saves preserve the content version.
The imported unclassified text is labelled `Title: ...` followed by `Description: ...`;
null source fields produce empty label values, without changing the source fields.
No new CV field classification or contact permission is established by this representation.

All selected imports, CV append, duplicate ledger and review confirmation commit atomically.
The runtime import role can read the source but cannot update it. Existing M2 subject fencing
and Account → Membership → Profile locking precede document access; no new lock namespace.
Learning-owned review/ledger tables use the existing Learning history and FORCE RLS. No
shared foreign keys, cascade/retention policies or hosted migrations are introduced.

API support is explicitly mapped only by a Testing controlled host. Production purpose,
session/standing and coordinated authority adapters, registration and activation remain
outstanding. The decision does not authorize production activation or public sharing.
